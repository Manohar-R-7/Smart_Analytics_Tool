# Smart Analytics Tool

## Project Overview

This project is a simple analytics tool that helps users analyze datasets quickly.

## Features

* CSV Upload
* Dataset Preview
* Missing Value Analysis
* Statistical Summary
* Dynamic Visualizations

## Technologies Used

* Python
* Pandas
* Plotly
* Google Colab

## How to Run

1. Open the notebook.
2. Upload a CSV file.
3. Run all cells.
4. Review analysis results and visualizations.

## Output

The notebook generates dataset insights, statistical summaries, and visualizations automatically.
